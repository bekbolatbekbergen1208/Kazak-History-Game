# ТАРИХИ МИССИЯ · Сыныптық архив

**Next.js + TypeScript + Supabase** негізіндегі қазақ тіліндегі classroom game. Мұғалім сабақ ашады; оқушылар аты және 6 цифрлық код арқылы қосылады. Тіркелу, email, пароль және Supabase Auth аккаунттары қажет емес.

## Жылдам іске қосу

Node.js 22 немесе 24 LTS қолданыңыз.

```sh
npm install
cp .env.example .env.local
```

1. Supabase жобасын жасаңыз немесе қолданыстағы жобаңызды таңдаңыз.
2. Supabase SQL Editor арқылы **`supabase/migrations/202609230001_classroom.sql`** файлын толығымен орындаңыз. Миграция бос схемаға арналған; қайта орындамаңыз. CLI пайдалансаңыз: `supabase db push`.
3. Supabase Connect / Project Settings → API бөлімінен `.env.local` мәндерін толтырыңыз:

| Айнымалы | Қызметі |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Жобаның `https://….supabase.co` мекенжайы |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Браузерге арналған publishable key; legacy **anon** key де жарайды |
| `SUPABASE_SECRET_KEY` | Тек серверге арналған secret key; legacy **service_role** key де жарайды |
| `NEXT_PUBLIC_SITE_URL` | Оқушылар аша алатын сайттың толық URL-і; QR және қосылу сілтемесіне пайдаланылады |

4. Supabase Realtime баптауында **public channels** рұқсаты қосулы болсын. Біз тек бос invalidation хабарламаларын таратамыз; жеке деректер public channel арқылы берілмейді. Кестелерді Postgres Changes publication-ына қосудың қажеті жоқ: миграция `realtime.send()` триггерлерін орнатады.
5. Серверді іске қосыңыз:

```sh
npm run dev
```

Браузер: **http://localhost:3000**. Телефонмен тексергенде компьютермен бір Wi-Fi желісіне қосылыңыз және `NEXT_PUBLIC_SITE_URL=http://КОМПЬЮТЕРДІҢ_LAN_IP:3000` қойыңыз. QR ішіндегі `localhost` басқа телефонда сіздің компьютеріңізді ашпайды. Интернет арқылы сыныпқа қолдану үшін сайтты HTTPS доменіне жариялаңыз.

Production:

```sh
npm run build
npm start
```

Бұл — Node.js сервері бар толық Next.js қолданбасы. Статикалық `dist/` ретінде жарияланбайды. Vercel немесе Node.js сервері жарайды. Жариялағанда төрт environment variable-ды хостингте де орнатып, қайта build жасаңыз. Google Fonts қолжетімсіз болса, жүйелік қаріптер қолданылады.

**Supabase параметрлері жоқ болса:** бастапқы бет пен қосылу формасы ашылады, бірақ сабақ жасау API-і түсінікті 503 қатесін қайтарады. Жалған қатысушылар немесе уақытша өндірістік memory-database қолданылмайды.

## Сабақты өткізу

### Мұғалім

1. Басты беттен **Сабақ ашу** басыңыз. 6 цифрлық код, QR және қосылу сілтемесі жасалады.
2. **Проектор экраны** батырмасын басып, бөлек анонимді экранды үлкен экранға шығарыңыз. Жеке мұғалім панелін проекторға шығармаңыз.
3. Оқушылар аты мен кодпен қосылады. Лоббидегі тізім бірден жаңарады.
4. **Ойынды бастау** барлық оқушыда ортақ 12 минуттық таймерді бастайды.
5. **Үзіліс / Жалғастыру**, **Жауаптарды жабу / ашу**, **Келесі миссия**, **Сабақты аяқтау** басқаруын пайдаланыңыз.

Миссиялар мұғалімнің пәрменімен ашылады. Бір архивті ерте аяқтаған оқушы келесі миссияны күтеді. Мұғалім келесі миссияға өткенде аяқталмаған тапсырмаларға ұпай берілмейді; интерфейс растау алдында соны түсіндіреді. Таймер 00:00 болғанда сабақ автоматты аяқталмайды. Үзіліс ұзақтығы таймерге қосылады.

### Ортақ тапсырма

- Ағымдағы миссияның choice тапсырмасын таңдап, **Сыныпқа көрсету** басыңыз.
- Жеке архивтер уақытша күте тұрады. Сыныптың әр оқушысы бір жауап жібереді.
- Сол сәттегі қатысушылар тізімі айналым үшін бекітіледі. Кейін қосылған оқушы келесі ортақ сұрақтан немесе жеке режимнен қатысады.
- Анонимді A/B/C/D үлестірімі проекторда бірден жаңарады. Бірнеше нұсқалы сұрақтарда үлестердің қосындысы 100%-дан асуы мүмкін.
- Барлық жауап түскенде **Дұрыс жауапты көрсету** қолжетімді болады. Күту қажет болмаса, алдымен жауаптарды жабыңыз.
- Жауап ашылған соң сол айналымда жауап қабылдау қайта ашылмайды. Жаңа айналымды немесе **Жеке зерттеуге оралу** пәрменін қолданыңыз.
- Ортақ сұрақ бұрын жеке орындалса, ұпай қайта қосылмайды. Қате ортақ жауап жеке режимде қайта зерттеледі.

### Жеке тапсырма

Drag-and-drop, сәйкестендіру, хронология, карта және рефлексия оқушы құрылғысында орындалады. Телефонда карточка → санат ретімен түртуге болады. Пернетақтамен Tab / Enter да жұмыс істейді.

17 архив тапсырмасы + 1916 финалы: **25 + 30 + 35 + 10 = 100 ұпай**. Тексеруге жіберілген қате жауап −1 ұпай; тапсырма максимумы жартысынан төмен түспейді (жоғары қарай дөңгелектеледі). Карточканы жылжыту өздігінен ұпай шегермейді. Көмек тегін. Рефлексияның тарихи сапасын мұғалім бағалайды; автоматты тексеріс тек 2–3 жарамды дәлел мен кемінде 15 таңбалық қорытынды барын тексереді.

## Деректер және құпиялылық

- `rooms`: сабақ коды, ойын күйі, миссия, айналым, жауап құлпы, таймер, аяқталу және expiry.
- `participants`: оқушы аты, жеке уақытша capability token-нің SHA-256 хэші, соңғы байланыс уақыты.
- `responses`: әр жіберілген жауап, дұрыстығы, алынған ұпай, айналым және idempotency key.
- `progress`: сервер есептеген ұпай, орындалған тапсырмалар, drafts, аяқталу уақыты.
- `classroom_limits`: сабақ ашу, қосылу және жауап жіберу сұрауларының шектеулері.

Барлық негізгі кестелерде **RLS қосулы**, `anon` және `authenticated` рөлдеріне тікелей кесте немесе privileged RPC рұқсаты жоқ. Next.js API серверлік Supabase кілтімен жұмыс істейді. Мұғалім және оқушы рұқсаттары бөлек 256-биттік capability token арқылы тексеріледі; браузерде `HttpOnly`, `SameSite=Lax` cookie қолданылады, production-да `Secure` қосылады. Cookie тазартылса, мұғалім рұқсатын немесе оқушының бұрынғы сәйкестігін тек аты арқылы қалпына келтіру мүмкін емес.

Room code — қосылу тәсілі; ол мұғалім рұқсатын бермейді. Оқушы өз дерегін ғана алады. Проектор API-і атауларды, жеке жауаптарды, participant ID-лерді, cookie-ді немесе жеке ұпайларды қайтармайды. Мұғалімнің жеке панелі ғана толық жауаптарды көреді. Service/secret key ешқашан `NEXT_PUBLIC_` айнымалысына қойылмайды.

Realtime арналары:

- `classroom:<room UUID>` — бастау, үзіліс, миссия және жалпы басқару өзгерді;
- `monitor:<room UUID>` — мұғалім/проектор статистикасы өзгерді;
- `student:<participant UUID>` — осы оқушының прогресі өзгерді.

Арна payload-ы әрқашан `{}`. Кез келген хабардан кейін клиент серверден рөліне сәйкес snapshot алады. Арнаға бөгде адам хабар жіберсе де, ол ұпайды не ойын күйін өзгерте алмайды. Қайта қосылғанда толық snapshot қайта оқылады; қосымша 10 секундтық reconciliation хабар жоғалса да күйді қалпына келтіреді. WebSocket байланысы сервердің тұрақты күйін алмастырмайды.

Ұпай браузерден қабылданбайды. Жауаптар серверде тарихи деректермен тексеріледі; атомарлық PostgreSQL функциясы pause/lock/mission/round шарттарын қайта тексеріп, транзакция ішінде жауап пен ұпайды сақтайды. Қайта жіберілген request ID екі рет ұпай қоспайды. Оқушыға берілетін task JSON бағалау кілтін қамтымайды.

## Байланыс үзілгенде

- «Қайта қосылуда…» күйі көрсетіледі.
- Оқушы drafts-ы localStorage-да және байланыс барда Supabase-те сақталады.
- Интернетсіз жіберілген жауап request ID-мен бірге жергілікті кезекке қойылады.
- Байланыс орнағанда сол ID-мен қайта жіберіледі. Сервер бұрын қабылдаса, бұрынғы нәтиже қайтарылады.
- Мұғалім осы арада миссияны ауыстырса немесе сабақты аяқтаса, ескі жауап жаңа тапсырмаға қолданылмайды; сервер оны түсінікті хабармен қабылдамайды.
- Жеке ұпай мен орындалған тапсырмалар Supabase-тен қайта жүктеледі. Жасырын жорамал ұпай есептелмейді.

## Статистика ережелері

Мұғалім оқушы санын, орташа ұпайды, барлық 18 тапсырма бойынша орташа прогресті, дұрыс жауаптар пайызын, әр оқушының тапсырмасы мен күйін көреді. Байланыс белгісі соңғы heartbeat бойынша 45 секунд шегінде анықталады.

Жалпы дәлдік пен қиын/жеңіл сұрақ рейтингі әр оқушының әр тапсырмаға **бірінші жауабы** бойынша есептеледі; қайталап түзету статистиканы жасанды жақсартпайды. Ағымдағы ортақ сұрақ диаграммасы тек ағымдағы айналымды көрсетеді. Миссия completion көрсеткіші — сол миссияның барлық тапсырмасын аяқтаған оқушылардың пайызы. Орташа аяқтау уақыты — жеке финалға жеткен оқушылар үшін, үзілістерді алып тастаған уақыт. Аяқтаған ешкім болмаса, ойдан уақыт көрсетілмейді.

Supabase-тің әдепкі 1 000 жол шегін ескеріп, response history беттермен оқылады.

## Автоматты тазалау

Жаңа сабақ 24 сағат сақталады. Мұғалім аяқтаған сабақ үшін қалған сақтау уақыты ең көбі 6 сағат. Мерзімі өткен сабаққа API кіруге рұқсат бермейді, cron әлі іске қосылмаса да.

Қалдық деректерді физикалық тазалау үшін Supabase Dashboard → Database → Extensions ішінен **pg_cron** қосып, **`supabase/schedule-cleanup.sql`** файлын бір рет іске қосыңыз. Ол 15 минут сайын `cleanup_classrooms()` орындайды. Room жойылғанда participants, responses, progress `ON DELETE CASCADE` арқылы жойылады. Басқа scheduler қолдансаңыз, осы RPC-ті тек серверлік кілтпен шақырыңыз. Cron орнатылмаса, expiry кіруді тоқтатады, бірақ жолдар автоматты жойылмайды.

## Тексеру

```sh
npm run typecheck
npm test
npm run build
```

`npm test` бастапқы ойын логикасын және миграцияны нақты PostgreSQL WASM қозғалтқышында (PGlite) тексереді: RLS/рұқсаттар, атомарлық жауаптар, idempotency, үзіліс, құлып, айналым roster-і, жауап ашу шарттары, expiry және cascade.

Көп браузерлі интеграциялық тест:

```sh
npx playwright install chromium
npm run test:classroom
```

Орнатылған Chrome-ды қолдануға да болады:

```sh
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" npm run test:classroom
```

Тест 3001 және 54329 порттарын уақытша пайдаланады, бөлек мұғалім, екі оқушы және проектор контекстін ашады. Тестке арналған PostgREST/Phoenix адаптері нақты миграцияны PGlite-те орындайды; ол production кодының бөлігі емес. **Бұл тест hosted Supabase желісін, жоба квотасын немесе оның Realtime баптауын тексермейді.** Нақты жобаға қосқан соң сол құрылғылармен QR → lobby → start → answer → pause → results жолын бір рет тексеріңіз. Тест нақты credentials талап етпейді және `.env.local` файлына жалған кілт жазбайды.

## Файлдар

- `src/app/` — Next.js беттері және API Route Handlers.
- `src/components/` — мұғалім, проектор, оқушы, join және ортақ архив интерфейсі.
- `src/lib/` — рұқсаттар, server grading, analytics, Realtime және validation.
- `src/data/historyData.ts` — мұғалім өзгертетін тарихи деректер.
- `supabase/migrations/` — кестелер, RPC, RLS және Realtime триггерлері.
- `tests/` — логика, SQL және браузерлік интеграциялық тесттер.

Тарихи мазмұн бастапқы оқу материалынан сақталған. Петицияның берілмеген бес талабы мен депутаттардың толық тізімі `SOURCE CONTENT REQUIRED HERE` белгісі бар құрылымдарда бос қалдырылған. Торғай мерзімдеріндегі бастапқы материал сәйкессіздігі картада түсіндіріледі. Сыртқы тарихи фактілер ойдан қосылмаған; карта шартты.

Техникалық анықтамалар: [Supabase Database Broadcast](https://supabase.com/docs/guides/realtime/broadcast), [Next.js cookies және Route Handlers](https://nextjs.org/docs/app/api-reference/functions/cookies).
